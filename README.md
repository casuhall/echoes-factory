- [X] Enregistrement de plans de fabrication
- [X] Etablissement système de tarification pour les objets (que ceux-ci soient des matériaux de production ou des objets finaux)
- [ ] Gestion d'un stock d'objets disponible dans l'usine
  - [X] Ajout d'objets unitaires
  - [X] Ajout d'un lot d'objets
  - [ ] Gestion des ISK ? (traitement isolé ? objet comme un autre ?)
  - [X] Réinitialisation
- [ ] Analyse et présentation d'un tableau de rentabilité comparé pour les plans de fabrication connus
  - [X] Rentabilité
  - [X] Gain attendu
  - [ ] Investissement restant nécessaire
  - [ ] Date de référence (date minimum de validité des estimations utilisées)
- [ ] Création d'un tableau de bord de production
  - [ ] Sélection d'une recette pour production
  - [ ] Préselection des sous objets à acheter / construire selon rentabilité
  - [ ] Proposition des prochaines étapes de constructions
  - [ ] Prise en compte d'objets en cours de construction
